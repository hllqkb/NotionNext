# 用手机发一篇博客

只管写，别的不用填。

1. 打开 Notion App，进博客数据库，点「新建」。默认就是「博客文章」模板，类型和状态已经帮你选好了（状态是 Draft，写一半不会被发出去）。
2. 写标题，写正文。正文第一行那句灰色提示可以删掉。
3. 写完把 status 改成 Published。站点下次重新部署后文章就上线了。

## 没填的东西会怎样

| 属性 | 不填时 |
| --- | --- |
| type | 当作文章（Post） |
| date | 用这篇页面的创建时间 |
| slug | 自动生成一个短链接，形如 `/article/p-1a2b3c4d`。以后改标题，链接也不会变。想要好看的链接就自己填 slug，但发出去以后别再改 |
| summary | 取正文开头约 120 个字。加密文章不会自动取，免得正文泄露 |
| category | 归到「随笔」 |

想改默认分类的名字：改 `themes/reading/config.js` 里的 `READING_DEFAULT_CATEGORY`。
